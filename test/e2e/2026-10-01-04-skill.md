## E2E-4: sync 端点实际写库验证(上轮 P1 深度)

**目的**: 上轮报告 P1 — sync 端点返回 true 但实际写库行为可疑,本轮要实际验证

**步骤**:
1. 创建 user-skill(经 UI):
   - navigate /admin/skills
   - 点击「新建」skill
   - name="测试同步 skill"
   - description="测试 sync 端点"
   - content="# 测试\n内容"
   - 提交(走 createApproved,admin)
2. 等待 skill 出现在列表,状态 APPROVED
3. 调 sync 端点(具体路径查代码,可能是 `GET /spring/ai/loom/api/skills/sync` 或类似):
   - evaluate_script 调 fetch API
   - 记录返回值
4. **重启服务**:
   ```bash
   kill $(pgrep -f 'spring-boot:run')
   export JAVA_HOME="/c/Program Files/Java/jdk-25.0.3"
   nohup mvn spring-boot:run -pl spring-ai-loom-agent-test -Dgpg.skip=true \
     > /tmp/mvn-restart.log 2>&1 &
   for i in $(seq 1 90); do
     curl -sf http://localhost:8080/spring/ai/loom/api/features > /dev/null && break
     sleep 2
   done
   ```
5. navigate /admin/skills → 断言「测试同步 skill」**仍在列表**
6. (chat) fill `调用 skill: 测试同步 skill` → 断言 LLM 响应含该 skill 内容
7. 截图

**断言**:
- sync 后 DB 持久
- 重启不丢失
- LLM 能调用

**截图**: `docs/notes/browser-baselines-2026-10-01/04-skill/sync-before-restart.png` + `sync-after-restart.png`
