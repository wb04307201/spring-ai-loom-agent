# 子系统 #3 — RBAC Tool picker E2E 剧本

**目标**: 验证 tool picker 显示 + RBAC tool 授权闭环 + universal tool 无感调用 + MCP server 失败保护
**前置**: Task 0 已给 base role 预授权 4 RBAC tool + Task 1 admin 登录完成
**预计 wall clock**: 15 min

---

## Smoke 用例: tool picker 弹出

**步骤**:
1. (admin 已登录 chat) 找到聊天 UI 「🔧 工具」按钮(或 MCP 按钮旧版)
2. click 按钮
3. take_snapshot → 断言 picker 弹出,含本地工具 + MCP server 两类
4. 截图

**断言**:
- picker 可见
- 含「本地」/「MCP」标签

**截图**: `docs/notes/browser-baselines-2026-10-01/03-rbac-tool/tool-picker-open.png`

## E2E-1: admin 选中 4 RBAC tool + 4 MCP server

**步骤**:
1. 在 picker 中勾选 4 个 RBAC tool(compile/git/maven/render)
2. 勾选 4 个 MCP server(网页抓取/必应/图表/顺序思维)
3. close picker
4. fill chat input "调用 git status 查看当前状态"(故意只测试 git,不实际触发 mvn/compile/render)
5. click 发送
6. SSE 检测
7. take_snapshot → 断言 LLM 响应中尝试调用 git tool(或响应「无 git 仓库」)
9. 截图

**断言**:
- picker 正确显示 RBAC 工具(因 base 已授权)
- LLM 能识别 tool 可用

**截图**: `docs/notes/browser-baselines-2026-10-01/03-rbac-tool/admin-tool-picker-checked.png` + `git-status-response.png`

---

## E2E-2: 普通 user (test-user-1) 登录 → 选中 RBAC tool 尝试 → 403

**步骤**:
1. 清 cookie → login.html
2. fill test-user-1 / TestPass123!
3. navigate index.html
4. click 「🔧 工具」按钮
5. take_snapshot → 断言:
   - 4 RBAC tool **disabled**(因 base role 已授权 test-user-1)
   - 或显示「需要 admin 授权」提示
6. (因已授权,实际可勾) 勾选 git → close
7. fill "调用 git status"
8. SSE 检测
9. take_snapshot → 断言响应正常(因 base 已授权)

**说明**: 因 Task 0 已预授权 base 含 4 RBAC tool,test-user-1 = base 角色,所以能调用。这里验证的是**tool 显示逻辑 + 闭环触发**

**截图**: `docs/notes/browser-baselines-2026-10-01/03-rbac-tool/user-rbac-tool.png`

## E2E-3: admin 撤销 base role 的 tool_git → 普通 user git 不可见(上轮 P2 闭环验证)

**步骤**:
1. 清 cookie → admin 登录
2. navigate /admin/roles/base/tools
3. 找到 tool_git → 取消勾选 → 保存
4. evaluate_script 检查 API `GET /admin/roles/base/tools` → 断言 tool_git 不在列表
5. 清 cookie → test-user-1 登录
6. navigate index.html → 「🔧 工具」
7. take_snapshot → 断言:
   - tool_git 不在 picker 中
   - 其他 3 RBAC tool 仍在
8. fill "调用 git status" → SSE
9. take_snapshot → 断言 LLM 响应「无 git 工具可用」或类似
10. **重要**: 恢复 admin 重新授权 tool_git(避免影响后续子系统)

**断言**:
- 撤销立即生效
- LLM 看不到已撤销的 tool

**截图**: `docs/notes/browser-baselines-2026-10-01/03-rbac-tool/revoke-tool-git.png` + `user-after-revoke.png`

## E2E-4: universal tool 7 个不展示在 picker(无感调用)

**步骤**:
1. (admin 登录,chat) click 「🔧 工具」
2. take_snapshot → 断言:
   - picker 中**不出现** tool_schedule / tool_subtask / tool_knowledge / tool_time / tool_skill / tool_file / tool_askUser
   - picker 仅显示 RBAC tool(compile/git/maven/render)和 MCP server
3. fill "现在几点"(应触发 tool_time,但 picker 不展示)
4. SSE 检测 → 断言响应含时间
5. 截图

**断言**:
- picker 无 universal tool 入口(无感调用)
- LLM 能调用 universal tool

**截图**: `docs/notes/browser-baselines-2026-10-01/03-rbac-tool/universal-not-shown.png`

## E2E-5(边界): MCP server 启动慢 → 单 server 跳过不影响其他

**步骤**:
1. navigate /admin → MCP 描述维护
2. take_snapshot → 检查 4 个 MCP server 状态(在线 / 离线 / 启动中)
3. **模拟 1 个 server 启动慢**: 通过 DevTools emulate networkConditions Slow 3G 持续 60s
4. 触发 chat 用到所有 MCP 的请求
5. SSE 检测
6. 断言: 单个 server 超时不影响其他 3 个 server 正常返回
7. 截图

**截图**: `docs/notes/browser-baselines-2026-10-01/03-rbac-tool/mcp-slow-server.png`

## E2E-6(边界): 重复勾选 / 反选 tool → 一致性

3. close picker → reopen
4. take_snapshot → 断言 picker 状态保留(不会随机重置)
5. 截图

## 失败处理

- 整剧本 3 次重试
- picker 不弹出 = CRITICAL(用户无法选择 tool)
- E2E-3 撤销不生效 = MAJOR(strict RBAC 闭环失败,上轮 P2 复发)
- 边界失败 = MAJOR/MINOR
