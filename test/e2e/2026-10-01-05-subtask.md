# 子系统 #5 — Sub-task 完整生命周期 E2E 剧本

**目标**: 验证子任务 PENDING → RUNNING → COMPLETED → CANCELLED 全状态机 + 跨会话隔离 + 超时防御
**前置**: Task 0 + Task 1 + Task 2(可触发子任务)完成
**预计 wall clock**: 20 min(含子任务 600s 等待)

---

1. (admin 登录 chat) 通过 Task 2 E2E-4 已触发 3 个并行子任务
2. take_snapshot → 断言 chip 渲染(若已完成,可能不显示,需重新触发)
3. 截图

## E2E-1: LLM 触发 start_sub_task → chip 显示 PENDING

**步骤**:
1. fill "调研 2026 年 Q3 全球 AI 行业最新进展"
2. click 发送
4. SSE 检测 ≤ 10s
5. take_snapshot → 断言:
   - chat 流中**至少 2 个 sub-task chip** 显示 ⏳ PENDING
   - chip 含 ID(8 hex chars) + 计时 0s + prompt 预览
6. 截图

**断言**:
- LLM 自主拆 ≥2 个子任务
- chip 立即显示

**截图**: `docs/notes/browser-baselines-2026-10-01/05-subtask/chip-pending.png`

---

## E2E-2: 子任务进入 RUNNING → 进度更新

**步骤**:
1. (接 E2E-1) 等 5s
2. take_snapshot → 断言:
   - chip 状态变为 RUNNING / ⚙️ / 进度更新
   - 计时累加
3. 等 10s 再观察
4. 截图

**截图**: `docs/notes/browser-baselines-2026-10-01/05-subtask/chip-running.png`

---

## E2E-3: 子任务 COMPLETED → 状态变更 + 主对话接收结果

**步骤**:
1. (接 E2E-2) 等所有 chip 变 ✅ COMPLETED(最长 600s,轮询 5s)
2. take_snapshot → 断言:
   - 所有 chip 变 ✅
   - 主对话流末尾出现综合结果
3. 截图

**断言**:
- 完整生命周期轮转
- 主对话接收所有子任务结果

**截图**: `docs/notes/browser-baselines-2026-10-01/05-subtask/chip-completed.png` + `subtask-aggregated-result.png`

## E2E-4: cancel_sub_task → 状态变 CANCELLED

**步骤**:
1. fill "调研 2026 年全球 AI 安全风险"
2. click 发送
3. 等 5s,子任务应进入 PENDING/RUNNING
4. fill "cancel_sub_task <子任务 ID>"
5. SSE 检测
6. take_snapshot → 断言:
   - chip 状态变 ❌ CANCELLED
   - 主对话接收「已取消」结果
7. 截图

**断言**:
- 取消生效
- 状态正确变更

**截图**: `docs/notes/browser-baselines-2026-10-01/05-subtask/chip-cancelled.png`

## E2E-6(边界): 子任务失败 → 错误信息展示

**步骤**:
1. fill "执行一个会失败的子任务,例如调一个不存在的 URL 抓取"
2. click 发送
3. 等子任务失败
4. take_snapshot → 断言:
   - chip 状态变 ❌ FAILED
   - 错误信息可见(可能折叠)
   - 主对话接收「子任务失败」结果
5. 截图

**截图**: `docs/notes/browser-baselines-2026-10-01/05-subtask/chip-failed.png`

## E2E-7(边界): 跨会话隔离

**步骤**:
1. (admin 登录 chat) 触发子任务,记录 conversationId
2. 退出 chat → 新建会话
3. 触发另一组子任务,记录新 conversationId
4. take_snapshot → 断言:
   - 两组子任务的 chip 分别在各自会话
   - chip ID 不重复
5. 跨会话查 list_sub_tasks → 断言仅返回当前会话子任务
6. 截图

**截图**: `docs/notes/browser-baselines-2026-10-01/05-subtask/cross-session-isolation.png`

## 失败处理

- 整剧本 3 次重试(单 E2E 子任务超时 90s)
- E2E-1/3 失败 = CRITICAL(子任务核心)
- E2E-5 超时配置错误 = MAJOR(防御失效)
- 边界 E2E-6/7 失败 = MAJOR/MINOR
