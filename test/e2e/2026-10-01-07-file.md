## E2E-2: 上传图片 → 预览可见

**步骤**:
1. 准备 1x1 PNG `/tmp/e2e-test.png`:
   ```bash
   # 创建最小 PNG
   python3 -c "
   import struct, zlib
   def png_chunk(t, d):
       return struct.pack('>I', len(d)) + t + d + struct.pack('>I', zlib.crc32(t + d))
   sig = b'\x89PNG\r\n\x1a\n'
   ihdr = png_chunk(b'IHDR', struct.pack('>IIBBBBB', 1, 1, 8, 2, 0, 0, 0))
   idat = png_chunk(b'IDAT', zlib.compress(b'\x00\xff\xff\xff'))
   iend = png_chunk(b'IEND', b'')
   open('/tmp/e2e-test.png', 'wb').write(sig + ihdr + idat + iend)
   "
   ```
2. 上传
3. take_snapshot → 断言:
   - 列表显示图片
   - hover / click 显示预览缩略图
4. 截图

**截图**: `docs/notes/browser-baselines-2026-10-01/07-file/upload-image-preview.png`
