# 子系统 #1 — 登录 + Cookie 认证 E2E 剧本

**目标**: 验证登录页面可达 + admin / 普通 user 登录成功 + 错误密码拒绝 + Cookie 持久化 + 边界(XSS/SQL)
**前置**: Task 0 fixture 完成 (有 pageId + 3 个用户)
**预计 wall clock**: 8 min

---

## Smoke 用例: login.html 可达

**步骤**:
1. 调 `mcp__chrome-devtools__navigate_page` pageId type=url url="http://localhost:8080/login.html"
2. 调 `mcp__chrome-devtools__take_snapshot` pageId
3. 调 `mcp__chrome-devtools__list_console_messages` pageId types=["error"]

**断言**:
- snapshot 含 `textbox` (username) + `textbox` (password) + `button "登录"`
- console 0 个 error

**截图**: `docs/notes/browser-baselines-2026-10-01/01-login/login.png`

---

## E2E-1: admin (wb04307201) 登录

**步骤**:
1. `mcp__chrome-devtools__fill` pageId uid=`<username textbox>` value="wb04307201"
2. `mcp__chrome-devtools__fill` pageId uid=`<password textbox>` value="123456"
3. `mcp__chrome-devtools__click` pageId uid=`<submit 按钮>`
4. `mcp__chrome-devtools__wait_for` pageId text=["chat input", "发送", "请输入消息"]
5. 调 `evaluate_script` pageId function=`() => window.location.pathname` → 断言 "/index.html"

**断言**:
- 跳转 index.html
- chat input 可见
- 「管理员」菜单可见(只有 admin 看得到)

**截图**: `docs/notes/browser-baselines-2026-10-01/01-login/admin-logged-in.png`

---

## E2E-2: 错误密码登录(完整流程,非简化)

**步骤**:
1. 清 cookie:`evaluate_script` pageId function=`() => { document.cookie.split(';').forEach(c => { const eqPos = c.indexOf('='); const name = eqPos > -1 ? c.substr(0, eqPos) : c; document.cookie = name + '=;expires=Thu, 01 Jan 1970 00:00:00 GMT;path=/'; }); return document.cookie || 'cleared'; }`
2. `navigate_page` pageId type=url url="http://localhost:8080/login.html"
3. fill username="wb04307201", password="wrong_password_999"
4. click submit
5. wait_for pageId text=["登录", "错误", "失败", "密码"] (任一错误指示)
6. take_snapshot → 断言仍在 login.html
7. evaluate_script → 检查 cookie 仍未设置新值

**断言**:
- 仍停留 login.html(URL 不变)
- 显示错误提示(中文)
- cookie 未设置新 session

**截图**: `docs/notes/browser-baselines-2026-10-01/01-login/wrong-password.png`

## E2E-3: 普通 user (test-user-1) 登录

**步骤**:
1. 清 cookie(同 E2E-2 步骤 1)
2. navigate_page login.html
3. fill username="test-user-1", password="TestPass123!"
4. click submit
5. wait_for pageId text=["chat input"]
6. take_snapshot → 断言:
   - 「管理员」菜单**不可见**
   - chat input 可见
7. evaluate_script → 列出顶部 nav 所有 menu item,断言无 `/admin` 入口

**断言**:
- 跳转 index.html
- 「管理员」菜单不可见
- 普通 user 工具栏可见

**截图**: `docs/notes/browser-baselines-2026-10-01/01-login/normal-user-logged-in.png`

## E2E-4: Cookie 持久化

**步骤**:
1. (接 E2E-3,user 已登录)
2. **不关浏览器**,`evaluate_script` pageId function=`() => document.cookie` → 记录 cookie 值
3. `navigate_page` pageId type=url url="http://localhost:8080/index.html"
4. wait_for pageId text=["chat input"]
5. 断言: 直接进 index.html,无需重新登录
6. `navigate_page` pageId type=url url="http://localhost:8080/admin/users"
7. 断言: 普通 user 访问 /admin → 403 / redirect 到 /index.html / 显示「无权限」

**截图**: `docs/notes/browser-baselines-2026-10-01/01-login/cookie-persist.png`

## E2E-5(边界): XSS 尝试

**步骤**:
1. 清 cookie → navigate login.html
2. fill username="<script>alert('XSS')</script>", password="anything"
3. click submit
4. take_snapshot → 断言:
   - 页面正常渲染(无弹窗,无 DOM 注入)
   - 显示「用户名或密码错误」(用户名当字符串处理,不执行)
5. console 0 个 XSS-related error

**截图**: `docs/notes/browser-baselines-2026-10-01/01-login/xss-attempt.png`

---

## E2E-6(边界): SQL 注入尝试

**步骤**:
1. 清 cookie → navigate login.html
2. fill username="admin' OR '1'='1", password="' OR '1'='1"
3. click submit
4. wait_for pageId text=["错误", "失败"] (任一错误指示)
5. take_snapshot → 断言:
   - 显示错误(未登录成功)
   - DB 无新 session 写入(可经 console 检查)
6. **不破坏** 后端数据库(再次用 wb04307201 / 123456 能正常登录)

**截图**: `docs/notes/browser-baselines-2026-10-01/01-login/sql-injection.png`

## 失败处理

- 整剧本 3 次重试
- E2E-1 失败 = CRITICAL(阻断后续所有子系统) → abort
- 边界 E2E-5/6 失败 = MAJOR(安全洞)
- 其他失败 = MAJOR
