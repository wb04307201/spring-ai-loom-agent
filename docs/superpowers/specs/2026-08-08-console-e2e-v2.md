## 🎯 关键发现

### 1. instanceof vs interface dispatch bug
第一轮实现用 `chat instanceof DefaultChat dc` 检查，**总是 false**（Spring 代理下类型不对）。改用接口 default method `IChat.buildDynamicSystemPrompt` 后正常。教训：**跨 bean 调用应通过接口**，不要 instanceof。

### 2. H2 AUTO_SERVER 内存 fallback
`rm -rf ~/.loom/datasource` + `DB_CLOSE_DELAY=-1` + `AUTO_SERVER=TRUE` 组合下，H2 即使文件被删，依然保留 in-memory 状态，下次启动恢复。**真正清空需要**：
- stop app
- `rm -rf ~/.loom/datasource/*` (with app stopped)
- start app

### 3. stats 与 events 语义差异（已澄清）
- `stats.scheduleCount = N` — 声明数（用户创建了几个定时任务）
- `events SCHEDULE = M` — 触发数（这些任务被执行了几次）
- 一个 schedule 可触发 N 次 → stats=1 events=N
- 例：3ae0deec "5 分钟报时"跑了 70 次 → stats=1 events=70
